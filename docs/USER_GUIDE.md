# User Guide

## Home

Shows generated data counts and extraction warnings.

## Wiki

Searches locally extracted PDF text from FAQ, features, changelog, game/download pages, and gallery references.

## Pokedex

Searches generated species data from NextDex. Species records include confidence labels and source-derived stats/types where available.

## Moves, Abilities, Sub-Abilities

Current records preserve numeric IDs because the bundled NextDex JSON did not include names. Treat them as source references, not human-friendly final data.

## Locations and Trainers

Searches spreadsheet-derived rows. These are useful for navigation but low-confidence until workbook columns are mapped more precisely.

## Save Manager

Choose a local save file to calculate file size, likely format, SHA-256, and a 256-byte hex preview. Export debug JSON for research. The app does not upload or write save data.

## Team Builder

Displays mock owned Pokemon until party/PC parsing is fixture-confirmed. Recommendations are intentionally conservative and show uncertainty.

## Debug/Compare

Choose two local save files to compare byte ranges. Use this to research clean vs played saves without mutating either file.
