# Data Inventory

Generated by `npm.cmd run data:generate` from local raw sources.

## Current Generated Outputs

- `species.json`: normalized species records from `ER-nextdex-main/static/js/data/gameDataV2.65beta.json`
- `learnsets.json`: named source-derived move references grouped by species
- `evolutions.json`: evolution references from NextDex JSON; method labels still need enum mapping
- `moves.json`: named move records from structured NextDex static data
- `abilities.json`: named ability records from structured NextDex static data
- `subabilities.json`: named innate/sub-ability records from structured NextDex static data
- `items.json`: named item records from structured NextDex static data
- `locations.json`: low-confidence rows from the earliest locations workbook
- `trainers.json`: low-confidence rows from trainer-location workbook sheets
- `mechanics.json`: searchable text extracted from PDFs
- `search-index.json`: local search documents across generated datasets
- `manifest.json`: source provenance, counts, warnings, and generation timestamp
- `warnings.json`: extraction warnings
