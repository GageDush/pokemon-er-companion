# Data Inventory

Generated by `npm.cmd run data:generate` from local raw sources.

## Current Generated Outputs

- `species.json`: normalized species records from `ER-nextdex-main/out/gameDataVVanilla.json`
- `learnsets.json`: low-confidence numeric move references grouped by species
- `evolutions.json`: low-confidence evolution references from NextDex JSON
- `moves.json`: low-confidence numeric move records because names were not present in the bundled JSON
- `abilities.json`: low-confidence numeric ability records
- `subabilities.json`: low-confidence numeric innate/sub-ability records
- `items.json`: empty until a reliable source is identified
- `locations.json`: low-confidence rows from the earliest locations workbook
- `trainers.json`: low-confidence rows from trainer-location workbook sheets
- `mechanics.json`: searchable text extracted from PDFs
- `search-index.json`: local search documents across generated datasets
- `manifest.json`: source provenance, counts, warnings, and generation timestamp
- `warnings.json`: extraction warnings
