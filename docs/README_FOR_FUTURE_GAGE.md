# Future Gage: Do Not Drift the Project

The goal is not just a pretty Pokédex.

The goal is a **local-first Pokémon Elite Redux operating manual + save-aware team manager**.

Keep the build honest:

- Static data first
- Save reading second
- Team recommendations third
- AI last
- Save writing much later, if ever

Do not let the project turn into:

- A generic Pokémon app
- A vanilla Emerald parser with Elite Redux labels
- A web-only wiki
- A cheat generator
- A hallucinating AI bot
- A half-finished UI with no source pipeline

The winning version of the app is boringly accurate, source-tracked, and safe.
